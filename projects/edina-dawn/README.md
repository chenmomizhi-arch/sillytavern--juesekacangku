# Edina Dawn

Source project: `圣女今天也很努力（大概）！`

Current active portraits live in `portraits/` and are referenced by stable `main` URLs. Prompts and generation records live in `prompts/`. Released card packages live in `cards/`.

The complete current set contains 28 portraits: the protagonist plus 27 named characters.

- Protagonist Edina Dawn (`portraits/edina.webp`).
- 8 sacred-maiden candidates.
- 15 open female characters.
- 4 male characters.

Current revisions include Eludi without a hand fan and with a subtle glowing forehead cross, Merl as a human idol, slender short-haired cat tails for Mimi and Yuffie, one clean single-side beauty mark for Celine and Beatrix, and Edina rebuilt from the live st-chatu8 character preset.

Edina's active portrait is driver-selected and overrides the generated candidates. It serves both the NPC relation-avatar slot and the protagonist avatar for preset 1. Preset-driven candidates that were generated from the live `st-chatu8` (智绘姬) configuration are retained under `archive/iterations/edina-v2` through `edina-v7`; that recipe used the global prompt preset `测试anima提示词`, quality tags `AQT_comfyui`, universal negative `UCP_comfyui`, ComfyUI worker `生图anima专用 (1)`, and the tag sets from `characterPresets["艾迪娜·晨曦"]` and `outfitPresets["[斗罗大陆Reborn V3.0 星海征途]纯白萝莉蕾丝长裙"]`.

Retired version folders and unused generated candidates live under `archive/`. Archived assets are backups, not active card dependencies.
